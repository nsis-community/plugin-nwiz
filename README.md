# Nwiz plug-ins for NSIS

![License](https://img.shields.io/github/license/nsis-community/plugin-nwiz?color=blue&style=for-the-badge)

> [!WARNING]
> **Work in progress.** This repository holds three plug-ins (Nmwdll, Nzipdll and Nzwdll) and isn't built automatically yet, so there are no releases. The DLLs in `Plugins/x86-ansi/` are the originals from the archive.

> [!NOTE]
> **Looking for the usage guide?** See [Docs/Nwiz/readme.txt](Docs/Nwiz/readme.txt).

This repository mirrors the Nwiz plug-ins, which were previously hosted on the [NSIS wiki](https://nsis.sourceforge.io/):

- **Nzipdll** extracts a zip file and shows a small progress banner.
- **Nmwdll** runs makensis and shows its output in a console window.
- **Nzwdll** combines both.

**Are you the author?** You're welcome to take it over: [open an issue](https://github.com/nsis-community/plugin-nwiz/issues/new) and we'll transfer the repository to you.
